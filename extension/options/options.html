Google Calendar

One-time setup: create a Google OAuth client ID
  1. Open the Google Cloud console and create a project (any name).
  2. Enable the Google Calendar API for it.
  3. Under Google Auth Platform, configure the consent screen: audience External, and add your Google address(es) as test users.
  4. Go to Clients → Create client → type Web application. Under Authorized redirect URIs, add:
  5. Copy the client ID it shows and paste it here.

iCal links no setup needed

Paste a private calendar link from any app — in Google Calendar it's Settings → your calendar → Integrate calendar → Secret address in iCal format. Outlook and iCloud "publish calendar" links work too.
